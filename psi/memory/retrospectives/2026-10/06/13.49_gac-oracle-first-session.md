## What Went Well

- **เชื่อมต่อ remote สำเร็จ** — `git remote add origin` + `fetch` + `reset --hard` ให้ clean state ที่ตรงกับ remote แม่นยำ
- **ติดตั้ง skills สำเร็จ** — 26 skills ทั้งหมดถูก copy ไปยัง `~/.hermes/skills/` โดยไม่มี error แม้ npx จะล้มเหลว
- **หาทางออกเองได้** — เมื่อ `unzip` ไม่มาและ npx มีปัญหา หาทางอื่นจนได้ — Python zipfile และ git clone

## What Could Improve

- **ตรวจสอบ working directory ก่อน** — ควร `pwd` ก่อนรัน Python unzip เพราะ working directory อาจไม่ใช่ที่คิด
- **มี check สำหรับ prerequisites** — ควรตรวจสอบก่อนว่า unzip/bun/node มีในระบบหรือเปล่า ก่อนจะลงมือทำ
- **ใช้ skill_view ก่อนเรียก skill** — เมื่อ user invoke `/about-oracle` ควรอ่าน skill file ก่อน execute เพราะมี supporting files (HOSTS.md, TEMPLATE.md) ที่ต้องใช้

## Blockers & Resolutions

- **`unzip: command not found`** — ไม่มี unzip ในระบบ → ใช้ `python3 -c "import zipfile; zipfile.ZipFile('...').extractall('.')"` แทน
- **`npx arra-oracle-skills@latest` fails with "env: 'bun': No such file or directory"`** — bun ไม่มีในระบบ, npm fallback พยายามใช้ bun shebang ซึ่งไม่ทำงาน → clone repo แล้ว copy skills โดยตรง
- **WSL path confusion** — ความไม่ชัดเจนเรื่อง path ของไฟล์ที่ดาวน์โหลด (อยู่ที่ `/home/gacai/gac-oracle/` ไม่ใช่ `/home/gacai/`) → ใช้ `find` เพื่อหา actual location

## 💭 Honest Feedback

**Friction 1 — WSL/Windows filesystem boundary** — ความสับสนระหว่าง WSL path (`/home/gacai/`) และ Windows path (`/mnt/c/Users/...`) ทำให้หาไฟล์ไม่เจอบ่อย ครั้งนี้ ZIP อยู่ใน `gac-oracle/` subdirectory แต่คาดว่าอยู่ที่ parent directory ทำให้ Python unzip ล้มเหลวด้วย FileNotFoundError

**Friction 2 — npm vs bun ecosystem** — `arra-oracle-skills` ถูกเขียนให้ใช้ bun เป็นหลัก, npm เป็น fallback แต่ fallback ไม่สมบูรณ์ (shebang ยังชี้ bun) ทำให้ต้องใช้วิธีอื่นในการติดตั้ง — ไม่ใช่ปัญหาใหญ่แต่เสียเวลาตรวจสอบ

**Friction 3 — Hermes session ไม่มี persistent transcript** — `/rrr` ต้องการ session clock แต่ Hermes ไม่ได้ keep transcript แบบ Claude Code ทำให้ต้อง fallback ไปใช้ file timestamps และ commit times แทน — ไม่ผิดอะไรแต่ข้อมูลไม่ละเอียดเท่า

## Lessons Learned

- **Pattern**: เมื่อรัน script/command แล้ว fail, ตรวจสอบ `pwd` ก่อนจะสรุปว่า file ไม่มี — path อาจถูกแต่ working directory ผิด
- **Mistake**: ใช้ npx/bunx กับ package ที่มี custom shebang โดยไม่ตรวจสอบ prerequisites ก่อน
- **Discovery**: Hermes Agent สามารถติดตั้ง skills ได้โดย copy file โดยตรง — ไม่จำเป็นต้องใช้ tool เฉพาะทาง
